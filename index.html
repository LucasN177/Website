01 — About me

The person behind the code

I'm Lucas – a Software Engineer and IT Consultant with a B.A. in Computer Science and more than four years of professional experience in the .NET ecosystem. I build modern web and desktop applications with C#, ASP.NET Core, Blazor and WPF, backed by Entity Framework Core, SignalR and Azure DevOps.

What I enjoy most is writing software that works well today and stays adaptable tomorrow. I like to understand the problem, the users and the constraints first – and then work in small steps with short feedback loops, automated tests and code reviews on every change.

Outside of work, I keep building side projects to try out new ideas and technologies – from splitting expenses and project management to a football tracker, a darts app and a code editor for tablets. You'll find them on my Dev Hub. Lately, I've been focusing more and more on Azure and on how AI can make .NET applications smarter.

“Clean architecture, testable code and a thoughtful user experience aren't extras for me – they're what makes the work fun.”
