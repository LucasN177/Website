About

A bit about me.

I'm Lucas — a software engineer and IT consultant with a B.A. in Computer Science and more than three years of professional experience in the .NET ecosystem. I build modern web and desktop applications with C#, ASP.NET Core, Blazor and WPF, backed by Entity Framework Core, SignalR and Azure DevOps.

What I enjoy most is writing software that works well today and stays adaptable tomorrow. Clean architecture, testable code and a thoughtful user experience aren't extras for me — they're what makes the work fun. Outside of work, I keep building side projects to try out new ideas and technologies.

See my skills

  • Clean architecture

    Clear boundaries and Domain-Driven Design keep complex systems understandable and easy to change.

  • Quality by default

    Unit, integration and end-to-end tests make every release predictable.

  • Performance-minded

    Caching, asynchronous patterns and efficient data access from day one.

  • Continuous learning

    Always exploring what's new in .NET to bring the right tools to every project.

How I work

How I approach a new piece of software

Small steps, short feedback loops and quality built in from the start.

  1. 01

    Discover

    First understand the problem, the users and the constraints — then start writing code.

  2. 02

    Architect

    Sketch a clean structure and pick the technologies that fit the job.

  3. 03

    Build & test

    Work in short iterations, with automated tests and code reviews on every change.

  4. 04

    Ship & evolve

    Deploy through CI/CD pipelines, learn from real usage and keep improving.
